## 1. tmux Configuration Comparison

| Feature | PR #1 | be-dev-agent | Gap |
|---------|-------|--------------|-----|
| Prefix key | `Ctrl-a` | `Ctrl-a` | None |
| Mouse support | Yes | Yes | None |
| Pane navigation | vim-style | vim-style | None |
| Scrollback | 10,000 | 50,000 | **PR is lower** |
| Escape time | 0ms | 0ms | None |
| Current path in splits | No | Yes | **Missing** |
| Status bar | Basic time | Context + pwd + time | **Missing my-context** |
| Popup bindings | None | Git/Jira popups | Optional |
| Layout files | None | PaymentService layout | Optional |
| Focus events | Not set | Enabled | **Missing** |
| Aggressive resize | Not set | Enabled | **Missing** |

### Critical Gaps:
1. **Split panes don't preserve path** - PR uses default, be-dev-agent uses `-c "#{pane_current_path}"`
2. **Lower scrollback** - 10k vs 50k (important for log review)
3. **No focus-events** - Breaks vim autoread on pane switch

### PR tmux.conf Additions Needed:
```tmux
# Preserve path when splitting
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"
bind c new-window -c "#{pane_current_path}"

# Increase scrollback for log review
set -g history-limit 50000

# Enable focus events (vim integration)
set -g focus-events on

# Aggressive resize (multi-monitor)
setw -g aggressive-resize on
```

### PR bashrc Additions Needed:
```bash
# Prompt toggle for agent-friendly mode
prompt-min() {
    export PS1='\[\e[32m\]\u@\h:\w\$ \[\e[0m\]'
    echo "Minimal prompt (agent-friendly)"
}

prompt-full() {
    # Full prompt with git branch
    export PS1='\[\e[32m\]\u@\h\[\e[0m\]:\[\e[34m\]\w\[\e[33m\]$(parse_git_branch)\[\e[0m\]\$ '
    echo "Full prompt enabled"
}

# my-context shortcuts (database mode)
alias mcn='export MY_CONTEXT_HOME=db && my-context note'
alias mcs='export MY_CONTEXT_HOME=db && my-context show'
alias mcl='export MY_CONTEXT_HOME=db && my-context list'

# Java version switching (if needed)
java17() { export JAVA_HOME=/usr/lib/jvm/java-17-amazon-corretto; }
java21() { export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64; }
```
